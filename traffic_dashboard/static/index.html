Splunk 流量看板 · 初始化配置

连接你的 Splunk，三步开始使用
1 · 连接前的准备 2 · 配置 Splunk 连接 3 · 选择跟踪的索引

本看板通过 Splunk 管理 REST API（默认 8089 端口）查询各索引的日志量、摄入流量与磁盘占用。开始配置前请确认：

  • 运行看板的主机可以访问 Splunk 的 8089 管理端口（注意：不是网页控制台的 8000 端口）
  • 持有一个有搜索权限的 Token，或有搜索权限的账号密码
  • Splunk 使用自签名证书时，可在下一步关闭“验证 TLS 证书”
❓ 没有 Token？点这里查看获取指引
  1. Splunk 8.2 及以上：登录 Splunk Web → 设置（Settings）→ TOKEN → 新建令牌（New Token）→ 选择有效期与受众（audience，如 admin）→ 创建后立即复制（只显示一次）。
  2. 旧版本 / 页面里没有 TOKEN 入口：让管理员执行（替换地址与账号）： 
    curl -k -u admin:你的密码 https://<splunk主机>:8089/services/authorization/tokens \
     -d name=traffic-dashboard -d output_mode=json
# 返回 JSON 中的 "token" 字段即为 Bearer Token
  3. Token 对应的角色至少需要 search 能力，且能读取要统计的索引；不知道找谁要就问 Splunk 管理员。
  4. 也可以直接使用有搜索权限的账号密码（下一步选择“用户名 / 密码”方式）。
